Resilient Incident Triage Architecture

Complete fault-tolerant topology: dual-engine semantic vector caching (Redis 8 & NumPy fallback), dynamic 300s/60s TTLs, post-probe blindspot bridging, and self-repairing LangGraph inference.

Tier 1 · Cache Interceptor

Sub-20ms Dual-Engine Cache

  • Contextual Scope: Prepend [scope: service] before FastEmbed ONNX 384d vectorization.
  • Dual Engine: Primary Redis 8 RediSearch HNSW (sim ≥ 0.90); fallback NumPy dot-product (0.015ms).
  • Differential TTL: 300s healthy TTL; 60s degraded TTL for rapid upstream recovery re-evaluation.

Tier 2 · Orchestration & Guards

Post-Probe Blindspot Bridging

  • Pybreaker Sentinels: Concurrent asyncio.gather isolates failing Statuspage/Chaos probes.
  • Historical Compensation: Tripped breakers query cache at 0.70 similarity to inject prior resolutions.
  • Degraded Marking: Flags is_degraded = True and appends CIRCUIT_BREAKER_OPEN signal.

Tier 3 · Reasoning & Contracts

Strict Schema & 4-Way Routing

  • Groq Quota Failover: Intercepts HTTP 429 and fails over to secondary models automatically.
  • Pydantic v2 Contract: Enforces extra="forbid"; extracts tracebacks for 1-shot self-repair.
  • 4-Way Routing: Routes to Pass, Confidence Reflection (<0.60), Self-Repair (<2 retries), or Fallback P0.
