LangGraph State Machine & Resilience Lifecycle

Complete transition topology of the self-healing triage agent: dynamic probe targeting, compensatory blindspot bridging, 1-shot self-repair loops, and guaranteed fallbacks.

Phase 1 · Telemetry Routing

Post-Probe Decision Logic

  • All Breakers Closed: Concurrent probes pass cleanly into synthesize_telemetry.
  • Breaker Open: Routes to compensate_blindspots to query cache at 0.70 threshold.
  • Degraded Marking: Appends CIRCUIT_BREAKER_OPEN signal with error rate 1.0.

Phase 2 · LLM Inference

Groq LPU & Quota Failover

  • Zero Temperature: Strict JSON-mode generation targeting IncidentTriageReport.
  • HTTP 429 Interception: Automatic failover to secondary model if Groq quota exhausted.
  • Quota Telemetry: Records remaining tokens/requests in thread-safe tracker.

Phase 3 · Contract & Cycles

4-Way Validation Routing

  • Pass (Conf ≥ 0.60): Valid report proceeds to finalize_report and cache persistence.
  • Low Confidence (< 0.60): Triggers refine_reflection to deepen root cause analysis.
  • Validation Failure: Injects traceback into self_repair (up to 2 retries) or fails safe.
