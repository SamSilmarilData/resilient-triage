Fault-tolerant incident triage

Break its dependencies. It still answers.

This incident-triage agent never returns a 500 and never stalls. When Redis, Statuspage or the language model fails, it degrades instead: a slower path, a flagged source, a fallback report. How it's built

A FastAPI gateway checks a semantic cache, then runs a LangGraph state machine that reads telemetry, asks the model for a report and validates it against a strict schema. Each piece has a written decision record in the repository.

  • A cyclic state machine with no checkpointer, so every run is self-contained (ADR 0001, ADR 0007).
  • A semantic cache on Redis vector search, falling back to memory when Redis is down (ADR 0002).
  • Circuit breakers and retries around every telemetry source, under a deadline (ADR 0003).
  • Strict report contracts with self-repair when the model's JSON doesn't validate (ADR 0004).
  • One model gateway that owns failover and per-model cooldowns (ADR 0005, ADR 0006).
  • An execution trace, streamed as server-sent events, that draws everything on this page (ADR 0008, ADR 0009).
  • A build-free page: native modules, Preact and one stylesheet, all served from this origin (ADR 0010).

The HTTP API is documented at /docs.
